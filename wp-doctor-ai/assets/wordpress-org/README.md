# WordPress.org Asset Placeholders

Place final WordPress.org directory assets here before SVN submission or copy them to the WordPress.org SVN `/assets` directory:

- `banner-772x250.png` — standard plugin banner.
- `banner-1544x500.png` — high-resolution plugin banner.
- `icon-128x128.png` — standard plugin icon.
- `icon-256x256.png` — high-resolution plugin icon.

Use original artwork or GPL-compatible assets only. Do not include misleading badges, fake ratings, fake urgency, or unsubstantiated AI claims.
