# WP Doctor AI Pro

WP Doctor AI Pro is the premium add-on for the free WP Doctor AI plugin.

## What Pro unlocks

- Unlimited manual scans.
- Premium one-click AI solution plans.
- Google AI Studio / Gemini API key support.
- Custom AI language requests for any language supported by the AI provider.
- Premium checkout/account links pointed to <https://starlineinfotech.net/>.

## Required setup

1. Install and activate the free `wp-doctor-ai` plugin first.
2. Install and activate `wp-doctor-ai-pro`.
3. Open **WP Doctor AI > Premium AI setup**.
4. Add a Google AI Studio API key.
5. Run a scan, open an issue, and click **One-click solution**.

## Google AI Studio API key

Get a key from <https://aistudio.google.com/app/apikey>. Keep the key private. WP Doctor AI Pro sends only deterministic issue JSON to Gemini when a premium AI solution plan is requested.
